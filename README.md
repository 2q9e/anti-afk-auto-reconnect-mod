# Minecraft Anti-AFK & Auto-Reconnect Mod

A Minecraft mod project that aims to help players reduce idle disconnects and reconnect after an unexpected disconnect.

## Project status

This repository currently contains project documentation. Mod code, supported Minecraft versions, and release details will be added as development progresses.
